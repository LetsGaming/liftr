* **17 vs 18 tables (liftr-audit.md §3)**: The audit's data-model table inventory lists 17 tables and omits `bodyweight_logs`, which does exist in `packages/db/src/schema.ts:199-203`. The feature it backs ("bodyweight tracking with an EMA trend line") is mentioned in §5's feature inventory, so this is an inventory/count inaccuracy in §3 rather than a missing feature — flagged as a minor false positive on the specific "17 tables" claim.
* **Test-count/"no client component tests" staleness**: Not a false positive, but worth flagging — §6's "19 test files, 154 tests... no client component tests exist" is explicitly dated to the 2026-08-31 audit and is already superseded by the document's own later Round 4 claim of 218 tests, and by the current actual count of 260 tests across 28 files, including `packages/client/src/stores/activeWorkoutStore.spec.ts` (a Pinia store test). Since the document frames these as point-in-time snapshots rather than an evergreen claim, this is not scored as a false positive, but a reader relying on "no client tests exist" today would be misled.
